# Five Nights at Dibil Daddy

Браузерный 3D-хоррор на Three.js: пять ночей, бонусная ночь и три выбираемых персонажа.

## Цель

Дожить в спальне с 00:00 до 06:00. Dibil Daddy ходит по дому (его видно на камерах), подходит к двери спальни или прячется в вертикальном шкафу. Из шкафа его прогоняют так: открыть дверцы (Q) и светить на него фонариком около 2 секунд. Открытая дверь в его присутствии и шкаф без проверки приводят к одному из трёх сценариев поражения.

## Управление

- **WASD / стрелки** — ходьба по комнате.
- **Мышь / свайп справа** — обзор.
- **Shift** — быстрый шаг.
- **F** — бесконечный направленный фонарик.
- **E** — закрыть или открыть дверь.
- **C** — зажать рот во время икоты; на 3 секунды блокирует дверь и фонарик.
- **Q** — действие: взять планшет, открыть/закрыть шкаф, включить/выключить телевизор (смотри на предмет).
- **T** — открыть/закрыть планшет с камерами, **1–6** — переключить камеру.
- **Esc** — пауза.
- На телефоне доступны сенсорное перемещение, обзор и экранные кнопки действий.

## Системы

- Планшет лежит на столе: его нужно подобрать (Q), только потом работают камеры: Коридор, Зал, Вторая комната, Туалет, Гараж, Кухня.
- Телевизор у южной стены проигрывает эдит `public/video/tv-edit.mp4` со звуком (громкость зависит от расстояния).
- Игра работает на ПК и телефонах (стик слева, обзор справа, экранные кнопки).

- Два независимо планируемых пути отца, реакция на дверь и направленный свет.
- Паника и икота ускоряют следующие визиты.
- У героев разные преимущества: выдержка, тихий шаг или скорость.
- Шесть уровней сложности, три случайные концовки, победа и повтор ночи.
- Синтезированные шаги, скрипы, удары, сердцебиение и адаптивный фон.
- Прогресс и выбранный герой сохраняются локально в этом браузере.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Проверка: `CHROMIUM_PATH=/usr/bin/chromium node scripts/verify-game.mjs`.
